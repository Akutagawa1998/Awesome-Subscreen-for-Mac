日历接入隐私说明

更新日期：2026-10-19 · Google OAuth 配置名称：kiwi-dev

本说明仅覆盖 Wokyis Personal Calendar 的 Google Calendar 接入。这是本人在自己 Mac 上使用的本地工具，并非供公众注册的在线日历服务。

读取什么、用于什么

经账号本人授权后，应用读取账号标识和邮箱，用于区分账号；通过 Google Calendar 只读权限读取可访问的日历列表与所选日期范围内的事件，包括标题、时间、地点和日历链接，用于在本机操作台显示合并日程。应用不修改日历。

存储和传输

账号信息与 OAuth 凭据保存在本机项目的私有 .local/google.json，文件权限限制为当前用户读写；该文件不提交到源代码仓库。当前版本使用受文件权限保护的本地文件，未使用钥匙串加密。日程由本机服务向 Google API 读取并交给本机界面显示；操作台服务仅监听 127.0.0.1。

应用不将 Google 账号凭据或日程发送到此说明网站，也不为广告、分析、出售或模型训练分享这些数据。Google 登录和 API 请求由 Google 按其政策处理。本说明网站使用 GitHub Pages 托管，网页访问请求由 GitHub 按其政策处理；网站没有访问本机日历的接口。

保留与断开

本机账号凭据保留到本人在操作台断开对应连接或移除本机文件。断开连接会移除该账号在连接列表中的凭据；本人设置的身份允许名单及自行保存的备份不会因此清除。断开不会删除 Google 日历，也不会自动撤销 Google 端授权。

本人可在 Google 账号的第三方连接设置撤销 kiwi-dev 的授权，并自行删除本机私有文件及备份。撤销后，应用不能继续读取该账号的日历。

范围与反馈

本说明不覆盖操作台中其他独立集成功能。若有实现方面的问题，请通过项目问题页面反馈；请勿在公开问题中提交账号凭据、日程、健康数据或其他私人信息。
